# Third-party notices

The `wreath-linux` wheel dynamically links and bundles OpenSSL 3.5.2 under the
Apache License 2.0 for its native TLS transport. OpenSSL is a build input for
this opt-in Linux companion; it is not a dependency of the `wreath`
distribution.

Source: <https://github.com/openssl/openssl/tree/openssl-3.5.2>

The complete upstream license text is included in the wheel's `licenses/`
directory alongside Wreath's MPL-2.0 license.

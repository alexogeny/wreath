# `wreath.recording`

Request capture and recording *policies* — all deny-by-default. This module
ships the policy value types only: they describe what a Forensic-mode recorder
would be allowed to retain and validate that a policy stays inside its bounds.
No capture happens yet; the capture engine and `WFR1` sink are still to land,
and the never-capture field classes cannot be enabled through this API at all.

::: wreath.recording

# `wreath.typegen`

Generate TypeScript, fetch, and React-Query clients from the canonical route model.

Every name below is re-exported from `wreath.typegen`, so
`from wreath.typegen import build_api_model` works regardless of which submodule
defines it. The sections are grouped by submodule because that is where the
implementations — and their docstrings — live.

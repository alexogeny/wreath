# Email

`wreath.email` is the public home for mail Wreath already sends: SMTP delivery,
transactional-versus-marketing classification, suppression, one-click
unsubscribe, and DKIM signing.

It is a correct sending boundary, not an email service provider. Reputation,
IP warm-up, campaign management, and provider APIs remain outside the
framework.

::: wreath.email

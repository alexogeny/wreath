# MCP

`MCP` mounts streamable HTTP on a Wreath application or runs over stdio. Tools,
resources and prompts share the framework's binding, identity, authorization,
recording and progress boundaries.

::: wreath.mcp

Start with [Build an MCP server](../guides/mcp.md). The
[control-room story](../stories/mcp-control-room.md) adds OAuth, recent human proof and
resource updates.

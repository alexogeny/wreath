# v0.3.0

_Released 2026-08-16._

Wreath 0.3.0 expands the framework's production boundary: client and traffic
classification, serverless adapters, application-owned error reporting,
forensic HTTP replay, and inspectable deployment bundles now have first-party
surfaces. It also changes the default treatment of autonomous AI crawlers and
retires another broad set of superlinear hot paths.

## Breaking changes

- A bare `Wreath()` now denies known autonomous AI scrapers at native ingress
  and publishes matching `robots.txt` rules. Applications that intentionally
  accept all such traffic must construct `Wreath(ai_scraping="allow")`.
  Applications admitting selected products should configure
  `HttpPolicy(ai_scraping=AIScrapingPolicy(allow=(...)))`. User-triggered AI
  fetchers are not part of the denied scraper set.

## Added

- `LambdaAdapter` for API Gateway payload v1/v2 and Lambda Function URLs, plus
  warm Google Functions and Azure Functions adapters. Each adapter preserves
  one ASGI lifespan and event loop across warm invocations.
- Trust-aware client facts with bundled country and User-Agent databases,
  native lookup, Web Bot Auth integration, bounded metrics, and privacy-safe
  Flight/OTLP projection. `TrafficPolicy` can turn those facts into one named
  class for denial, tiered rate limiting, and Cedar authorization.
- Application-owned error reporting for unhandled HTTP, WebSocket, exception
  renderer, and background failures, with first-party Sentry, Rollbar, Bugsnag,
  and OTLP reporters. Reporter failures are isolated, counted, and logged.
- Completed outbound HTTP exchanges can be captured in Flight recordings and
  replayed as strict named client doubles. Replay refuses redacted, truncated,
  ambiguous, or request-mismatched exchanges instead of approximating them.
- `wreath infra bundle` renders a read-only Compose deployment bundle from an
  immutable OCI digest, including the machine-readable contract, inferred
  infrastructure plan, and checksums, without contacting or changing a live
  environment.
- `wreath port --verify` runs source and translated ASGI applications against
  an explicit corpus and compares status, repeated headers, and body bytes.
- Typed scalar feature flags, startup-validated `FlagSet` vocabularies, and an
  application-owned OpenFeature adapter. Existing boolean `FlagProvider`
  implementations remain supported through the same internal resolution path.
- Discoverable passkeys can serve as a first factor with usernameless login;
  SCIM collections support validated top-level sorting before paging; webhook
  sources accept first-party Standard Webhooks, Stripe, and GitHub verifiers;
  and Turnstile challenge verification uses Wreath's managed HTTP client.

## Changed

- Prometheus, OpenMetrics, StatsD/DogStatsD, and CloudWatch EMF share canonical
  counter-source discovery and explicit gauge semantics. Wreath also includes a
  dependency-free OTLP HTTP exporter for traces, metrics, and logs.
- AI-scraping refusals and client classification remain bounded native policy
  facts: expected policy denials are exported as structured Flight/OTLP
  dispositions, not reported as application exceptions or retained as raw IP
  and User-Agent values.
- Feature-flag providers may own lifespan startup and shutdown, and
  application-owned metric and client-fact providers are discovered without
  duplicate bridge-specific wiring.

## Fixed

- Cancellation-heavy pools and wait queues no longer rescan or front-delete
  their outstanding work, and tombstoned entries are compacted without
  changing cancellation semantics.
- Route registration, webhook verification, compiler passes, migration
  planning, type generation, and documentation tooling no longer repeatedly
  search or rebuild collections that have already been examined.

## Performance

- Twenty previously superlinear construction, cancellation, verification, and
  tooling paths now scale linearly or better. Across the ten new subjects and
  their same-size controls, the largest measured input doubling retired
  **1.005x to 2.094x** as many userspace instructions, the expected constant-to-
  linear range.
- Protobuf compilation now builds native JSON-name indexes and materializes
  positional objects once at the Python boundary. Cedar compilation stores
  direct edges and performs cycle-safe traversal in operation-owned native
  memory rather than reconstructing graph work in Python.

## Docs & internals

- The complexity contract now contains 140 controlled probes. The new static
  discovery ratchet records provably superlinear source shapes and rejects only
  newly introduced candidates until each is probed, restructured, or explicitly
  acknowledged.
- New reference material covers AWS Lambda, other serverless platforms, client
  facts and traffic policy, bot challenges, error reporting, outbound HTTP
  replay, deployment bundles, and behavioral verification for translated apps.

# README charts

These charts are generated from the retained holistic benchmark artifact. Anime.js
samples the entrance timing into plain numbers; the generator writes those samples
as self-contained SVG animation. No JavaScript or JavaScript dependency ships in
Wreath, its wheel, or the rendered README.

```bash
cd tools/readme_charts
bun install --frozen-lockfile
bun run generate
bun run check
```

`--check` compares regenerated bytes without writing. Each SVG also records the
SHA-256 of its source JSON so Python tests can reject stale assets without needing
Bun or `node_modules`.
